IPO

Input = data yang masuk. Process = data diolah. Output = hasil yang keluar.

CPU

ALU melakukan operasi aritmetika dan logika. CU mengatur jalannya instruksi.

RAM vs Storage

RAM adalah memori kerja sementara. SSD/HDD digunakan untuk menyimpan data secara lebih permanen.

Memory

Data dari storage dapat dimuat ke RAM agar dapat digunakan oleh CPU.
