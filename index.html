PREPARATION PHASE

Mini Lesson

Baca dan pahami konsep berikut sebelum masuk ke misi. Setelah itu kamu akan mengenali perangkat komputer melalui simulasi 3D.

Input → Process → Output

Input adalah data yang masuk ke komputer. Process adalah pengolahan data. Output adalah hasil yang keluar.

CPU

ALU menangani operasi aritmetika dan logika, sedangkan CU mengatur jalannya instruksi.

RAM vs Storage

RAM merupakan memori kerja sementara. SSD/HDD digunakan menyimpan data untuk digunakan kembali.

Komponen Komputer

Motherboard menghubungkan komponen, CPU memproses instruksi, RAM membantu pekerjaan aktif, dan storage menyimpan data.

Sebelum lanjut
