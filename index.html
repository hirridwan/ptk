LEARNING MODE

IPO

Input = data masuk ke komputer.

Process = data diolah oleh sistem.

Output = hasil pemrosesan keluar kepada pengguna.

CPU

ALU digunakan untuk operasi aritmetika dan logika.

CU mengatur dan mengendalikan jalannya instruksi.

RAM vs Storage

RAM merupakan memori kerja sementara.

SSD/HDD digunakan untuk menyimpan data agar dapat digunakan kembali.

Alur Komputer

Secara sederhana: Input → Process → Output.

Memory membantu menyimpan data yang sedang digunakan dan storage menyimpan data lebih permanen.

Sebelum lanjut:
Pastikan kamu sudah memahami perbedaan RAM dan storage, fungsi ALU dan CU, serta konsep dasar Input → Process → Output.
