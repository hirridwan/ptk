Mini Lesson

Baca bagian ini sebelum masuk ke Mission 1.

1. Input → Process → Output

Input adalah data yang masuk ke komputer. Process adalah pengolahan data. Output adalah hasil yang keluar.

Contoh: Keyboard → CPU → Monitor.

2. CPU

CPU adalah pusat pengolahan komputer. ALU melakukan operasi aritmetika dan logika. CU mengatur dan mengendalikan jalannya instruksi.

3. RAM dan Storage

RAM adalah memori kerja sementara. SSD/HDD menyimpan file dan data agar tetap tersedia ketika komputer dimatikan.

4. Cara Menjawab Misi

Baca kasus dengan teliti. Tentukan komponen yang tepat. Untuk uraian, jelaskan alasanmu, bukan hanya menyebutkan jawabannya.

Petunjuk Sebelum Mission 1
